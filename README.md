# Descripción del proyecto

Este proyecto es una demostración de maquetación web utilizando **CSS Grid** para organizar los elementos de la página de manera estructurada y eficiente. Está diseñado para mostrar cómo usar esta técnica avanzada de diseño web para construir páginas responsivas y organizadas.

## Contenido de la Publicación

El proyecto incluye una página web con las siguientes características:
- Un encabezado con el título del proyecto y el autor.
- Un menú de navegación colocado en una columna lateral.
- Una galería de imágenes organizada en un diseño de cuadrícula.
- Un pie de página con información de contacto y licencias.

## Desarrollo del Proyecto

Este proyecto fue creado utilizando:
- **HTML5** para la estructura del documento.
- **CSS3** con **Grid Layout** para el diseño.
- Imágenes ilustrativas alojadas en enlaces públicos.

El diseño es completamente responsivo, adaptándose a diferentes tamaños de pantalla gracias a las propiedades de CSS Grid.
